# Harvest Report "FCAJ Community Day & Agentic AI Build Week: AI Solution Building on AWS"

### Purpose of the Event

- **Explore Real-world AI Agent Use Cases:** Listen to team presentations on applying Agentic AI to ordering, security monitoring, and technical support.
- **Learn Multi-channel Architecture Design:** Discover how to integrate AI Agents directly into familiar messaging platforms like Zalo and Messenger without app switching.
- **Experience the 24h Hackathon Journey:** Hear authentic stories, time-pressure realities, and key lessons from building MVP products in 24 hours.
- **Automate Engineering Workflows (SA):** Explore AI Native solutions that automate document analysis, architecture diagramming, and AWS cost estimation.

- **KFC Bot Agent Project (One Team):** Anh Duy, Tran Dong, Doan Trung, Minh Viet, Anshul Roy.
- **S.H.E.P.H.E.R.D Project (3KA Team):** Huynh An Khuong, Nguyen Quoc Huy, Ngo Quang Khoi, Hoang Le Thanh Duc, Dang Nguyen Phuoc Loc.

### Key Highlights

#### KFC Bot Agent Project: Multi-channel Ordering AI Agent (One Team)

- **The Lost Order Problem:** The team shared practical insights on how forcing users to exit chat apps to open food delivery apps causes order drop-offs. AI ordering is difficult because natural language is unstructured while business rules are strict.
- **Ordering Without Leaving the Chat:** Building an AI Bot running directly on Zalo/Messenger allows customers to order food inside their ongoing conversation without creating new accounts or switching apps.
- **5-Step Agent Loop:** Listened to the team explain the core process from *Goal* → *Plan* → *Tools* → *Act* → *Verify*.
- **"Design Once, Deploy Everywhere":** Designing standardized Adapter/Connector layers enables effortless expansion to new chat channels without rewriting codebase from scratch.

#### S.H.E.P.H.E.R.D Project: Crowd Monitoring & Security Alerts (3KA Team)

- **24-Hour Hackathon Journey:** Lighthearted stories about 24h pressure: late-night walks, drinking 5 cans of Redbull, accidentally committing `.env` files to GitHub, and debugging until 3 AM.
- **Event Camera Monitoring:** Noticing manual gate tracking misses congestion, the team combined YOLO + ByteTrack with AI Agents to measure crowd density and estimate queue times.
- **Operator Copilot Assistant:** Empowers security staff to ask questions in natural language and receive real-time incident resolution suggestions instead of monitoring screens continuously.

#### SA Professional AI Native App: Automated Assistant for Solutions Architects (Plan V Team)

- **Solving SA Pain Points:** Highlighted how SAs spend excessive time reading documents, drawing diagrams, and estimating AWS budgets manually whenever clients request designs.
- **Automated Design Workflow:** The app accepts raw docs/audio to extract requirements, auto-generates editable Draw.io/AWS diagrams, and estimates directional AWS costs within minutes.

#### Signal Scout Project: Corporate Restructuring Signal Platform (Dream AI Team)

- **Connecting Scattered Data:** Learned how combining Web Crawlers with analytical Agents gathers news, financial movements, and early warnings on corporate strategy shifts.
- **Execution Takeaway:** The core lesson was that completing a small, working product matters more than an overambitious idea that fails to run.

### Key Takeaways

- **AI Agent Mindset:** An Agent goes beyond Q&A Chatbots by leveraging external tools and verifying real-world outputs.
- **Flexible System Architecture:** Applying Adapter patterns enables seamless integration with existing user platforms like Zalo without extra app installations.
- **Hackathon Lessons:** *"A small working product is better than a broken big idea"*, and teamwork spirit is paramount under time constraints.
- **Engineering Automation:** Harness AI to eliminate repetitive tasks like requirement extraction and architecture diagramming.

### Practical Applications

- **AI Agent Execution:** Apply the 5-step loop (Goal - Plan - Tools - Act - Verify) when designing practical automated AI assistants.
- **Messaging App Integration:** Consider embedding solutions directly into existing user chat platforms (like Zalo) to optimize user experience.
- **Workflow Optimization:** Use AI tools to draft architecture sketches and estimate AWS costs rapidly when preparing project proposals.
